9. SETUP & LOCAL DEVELOPMENT INSTRUCTIONS
--------------------------------------------------------------------------------
Prerequisites: Node.js (18.x or 20.x), Git, npm

A. Frontend Setup:
   git clone https://github.com/yashk40/MEDLAB.git
   cd MEDLAB/Medlab
   npm install
   npm run dev
   # Open http://localhost:3000

B. Backend Setup:
   cd MEDLAB/backend
   npm install
   npm run dev
   # Backend runs on http://localhost:5000

C. Production Build:
   cd MEDLAB/Medlab
